### Informasi Utama

Semua infromasi utama seperti nama pemilik situs about, avatar bio dan lain sebagai nya  sosial dan lainya ada di folder content > www > [lang] > [nama file].yml

informasi yang di sajikan harus berada di folder content dengan format yml tidak ada satu teks pun yang tampil di web langsung secara hard code lewat file react semua infromasi dapat di ubah di folder content tidak ada pengecualian


### Content blog sama seperti Infromasi utama 

semua blog di simpan di folder content > blog > [lang] > [nama files].md di tampilakna di sana tidak ada yang hardcode, blog juga harus lengkap miniaml ada informasi seperti ini 

```md
---
title: "Cara Memilih TLD yang Tepat untuk Meningkatkan Kredibilitas Bisnis"
subtitle: "Panduan untuk memilih TLD yang tepat untuk bisnis anda."
summary: "Panduan untuk memilih TLD yang tepat untuk bisnis anda."
image: "/images/blog/tld.png"
publishedAt: "2026-04-28"
tag: "Domain, Bisnis , SEO, Tips, Teknologi"
---

[markdown content here]
```

dan juga nama file itu = nama url path semisal user buka davingm.com/id/blog/namafilemd

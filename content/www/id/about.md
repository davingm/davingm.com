## Tentang Saya:

> Catatan:
>
> Seorang mahasiswa realistis, bukan seseorang yang bisa melakukan segalanya.

<img src="https://github.com/davingm.png" width="200" alt="Avatar" />

Nama saya **Davin Gahisan Mustafid**. Sejak kecil, teman-teman saya sudah terbiasa memanggil saya Kin. Saat ini saya berada di **Shenzhen, Tiongkok**, untuk mengembangkan sesuatu yang luar biasa.

Saya berfokus pada rekayasa frontend, TypeScript, Rust, Vue.js, serta optimalisasi performa Web modern. Saya sangat antusias terhadap teknologi baru, bahkan terkadang sulit menoleransi teknologi yang sudah usang hingga membuat saya sulit tidur. Jika ingin berteman dengan saya, cobalah memahami beberapa teknologi modern. Setelah itu, mari kita berdiskusi bersama!

Jangan lupa untuk selalu terhubung dengan saya kapan saja. Kunjungi halaman [Tautan](/id/links) untuk memasukkan diri Anda ke dalam daftar teman saya. Jangan lupa juga untuk mengikuti perkembangan terbaru saya seputar pengembangan perangkat lunak sumber terbuka melalui [GitHub](https://github.com/davingm).
